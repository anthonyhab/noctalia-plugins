# Documentation Index

## Active Docs

- `docs/MAINTENANCE.md` - repository workflow, stable/WIP policy, release and registry rules
- `docs/NOCTALIA_API.md` - comprehensive Noctalia API reference

## Planning History

- `docs/plans/` - implementation plans and audit notes

Historical or deprecated references should be removed instead of archived in-tree. Git history is the archive.

Use this order when updating docs:

1. Put durable workflow policy in `docs/MAINTENANCE.md`.
2. Keep API details in `docs/NOCTALIA_API.md`.
3. Keep plugin-specific protocol details with the plugin (for example `bb-auth/docs/`).
